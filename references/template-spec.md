# 模板逐字段规格（7 行 2 列表格）

模板 `papers.pptx` 的论文页是一张 7 行 2 列的表格。左列为标签（浅蓝底），右列为内容（浅灰蓝底）。坐标、列宽、字号一律从 `+xml-get` 回读的模板页 XML 抄，不要凭本文数字硬编码——本文只说明每个字段填什么。

## 表格字段

| 行 | 左列标签（照抄） | 右列填什么 |
|---|---|---|
| 1 | 文章名称 | 论文完整标题。英文标题原文照录；可附中文译名但以英文原题为主。 |
| 2 | 作者 | **一行**。格式：`作者A, 作者B, 作者C, 通讯作者D*`。超过一行只保留前三名 + 通讯作者（通讯作者名后加 `*`），用逗号分隔，不得换行。 |
| 3 | 单位 | 作者机构。多个机构用分号分隔；过长时按字号 12–13pt 缩适配，保持单元格内。 |
| 4 | 期刊及时间 | 如 `arXiv preprint, 2025`；会议论文写会议名 + 年份。中英混排。 |
| 5 | 关键词 | **纯中文关键词**，3–5 个，中文分号分隔。不要写英文术语。 |
| 6 | 内容总结 | 350–500 字详尽摘要：研究问题 → 核心方法/框架 → 关键实验结论（带数字）→ 创新点。用纯中文表达；模型/机构/数据集专名保留原名。 |
| 7 | 图片或原文摘录 | 论文代表性 Figure（PNG，原比例缩放，不裁内容）；无合适图时放关键结论句。 |

## 字号与适配参考（以模板 XML 实测为准）

- 标签列：黑体/宋体，与模板一致；约 12–13pt。
- 文章名称：标题级，加粗。
- 内容总结：11–12pt，视字数自适应；单元格区域约从 y=308 到 y=500（高约 192），写满不溢出即可。
- 单位、期刊：机构多/长时可降到 12–13pt 单行容纳。

## 配色（与模板严格一致）

- 标签列底色：`#B4C7E7`
- 内容列底色：`#E9EBF5`
- 文字与表格边框：黑色
- 右下角页码：保留模板页码 field，不要改位置（lint 会报 `table_covers_text`，属模板固有）。

## 内容总结写作示例（纯中文、避专名堆砌）

✅ 好："该方法把执行过程中的失败轨迹定位到具体代码位置，在有界失败窗口内联合修复多个失败，实验证实函数级引导与门控回滚均显著提升最终成功率。"

❌ 差："Grow-the-Harness 实现 agentic RL with function-level trace, 消融证实 ablation 显著提升。"（英文专名/术语堆砌会触发中文校对误判与波浪线。）

## 关键词栏示例（纯中文）

`执行框架生长; 失败引导训练; 函数级执行轨迹; 门控回滚; 可复用智能体`
